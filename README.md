# Mischa Pogrebnyak

Software & platform engineer working across backend development, cloud infrastructure and operations. I like making systems easier to run, troubleshoot and change.

At **Allane SE (formerly Sixt Leasing SE)**, my work includes AWS, Kubernetes/EKS, infrastructure as code, CI/CD and relational databases. My background is in Java and PHP backend development; my public projects also take me into Go, Rust and Vue.

## Public projects

### [ofenbau-app](https://github.com/mischapogr/ofenbau-app)
A website template for a fictional stove and fireplace business, with an interactive 3D planning explorer, material choices and a budget calculator. Built with Vue 3, Vite and Tailwind CSS, with Playwright tests and Cloudflare Pages deployment support. MIT licensed; the code runs locally, while hosted previews are available by invitation.

### [platform-ipam](https://github.com/mischapogr/platform-ipam)
IP address allocation with a PostgreSQL ledger, NetBox integration, and REST, CLI and Terraform clients. The focus is on predictable allocation, safe retries and a clear release lifecycle. **Development preview** with local simulation checks; live AWS integration remains unqualified.

The [companion Terraform provider](https://github.com/mischapogr/terraform-provider-platformipam) is available as a release candidate.

### [platform-signal](https://github.com/mischapogr/platform-signal)
A Rust project for durable log and security-event ingestion, Parquet storage, queries and rule-based findings. **In development**, with no production release yet; the repository records the current implementation and verification limits.

### [geonames-service](https://github.com/mischapogr/geonames-service)
A self-hosted PHP/MySQL API for multilingual city and place search, including coordinates and timezones. Uses [GeoNames](https://www.geonames.org/) data under CC BY 4.0.
